# LumaMath Glossary

## Purpose
This document defines the canonical vocabulary used across the LumaMath codebase, curriculum, and documentation. Consistent terminology prevents drift as more engineers and contributors join the project.

## Audience
Anyone writing, reviewing, or discussing LumaMath code, content, or design.

## Terms

**Lesson**
A single day's learning experience. A lesson includes the instructional cycle (Warm-Up, Learn, Try It, Practice) and optional assessment sections.

**Mission**
A student-facing learning objective within a concept, typically tied to one lesson. Missions appear on the learning path and are completed through lesson sections.

**Unit**
A curriculum grouping focused on a connected set of skills or concepts. Each unit contains several weeks of lessons and an evaluation.

**Concept**
A mathematical idea taught across one or more lessons. Concepts are larger than skills and smaller than units.

**Skill**
A specific, measurable capability a student should acquire. Skills are tagged to lessons and used for mastery tracking and gap analysis.

**Mastery**
Demonstrated, durable understanding of a skill or concept, including the ability to apply it in varied contexts. Mastery is tracked over time, not measured by a single quiz.

**Warm-Up**
The first section of a lesson. It activates prior knowledge and prepares the student for the day's concept.

**Learn**
The section where new material is introduced through teaching points, examples, and vocabulary.

**Try It**
A guided, low-stakes exercise where the student applies what was just learned with scaffolded support.

**Guided Practice**
Practice with built-in hints and worked examples, intended to build confidence before independent work.

**Independent Practice**
Practice without scaffolding, used to check whether a student can apply a skill on their own.

**Challenge**
An optional, more demanding practice mode that extends the lesson skill or combines it with earlier skills.

**Quick Check**
A short, in-lesson check for understanding, distinct from end-of-week evaluations.

**Evaluation**
A summative assessment at the end of a unit or week, used to measure mastery before moving on.

**Review**
Spaced practice of previously learned skills, often embedded in warm-ups, flashcards, or end-of-week spiral review.

**Curriculum**
The complete K–6 scope and sequence of units, weeks, lessons, skills, and assessments.

**Content Contract**
The agreement between authored content data and the components that render it. The contract is enforced by Zod schemas and runtime guards.

## Contributing
When introducing a new term, add it here before using it in code or documentation. If a term already exists, use the canonical form rather than a synonym.
