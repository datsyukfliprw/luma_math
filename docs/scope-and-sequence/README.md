# Scope and Sequence

## Purpose
This directory contains grade-specific scope and sequence documents. Each file records the units, weeks, standards, and lesson rhythm for one grade.

## Audience
Curriculum designers and product managers mapping long-term content plans.

## Relationship to `curriculum.md`
`docs/curriculum.md` defines the platform-wide K–6 curriculum organization, principles, and review workflow. The files in this directory are concrete instances of that organization for individual grades. Add a new file here when a grade's content is finalized.

## Files
- `grade-3.md` — the first implemented grade scope and sequence.
