# LumaMath Practice Type Plan

This file tracks the reusable practice behavior types needed for each unit.

The goal is **not** one practice file per day.  
The goal is one reusable behavior engine per repeated skill/activity type.

## Unit 1: Multiplication & Division Foundations

Status: In progress

### Week 1: Foundations of Multiplication — Equal Groups

- [x] `equal_groups`
  - Match equal-group models to multiplication expressions.
  - Example: 3 groups of 4 = 12.
- [x] `repeated_addition_to_multiplication`
  - Convert repeated addition into multiplication.
  - Example: 5 + 5 + 5 = 15 → 3 × 5 = 15.
- [x] `factor_product_identification`
  - Identify factors and products in multiplication equations.
  - Example: 3 × 4 = 12 → factors are 3 and 4, product is 12.
- [ ] `equal_groups_with_objects`
  - Build or interpret equal groups using object-based prompts.
  - Example: Arrange buttons/blocks into equal piles.
- [ ] `mixed_evaluation`
  - Balanced review pulling from multiple practice types.

### Week 2: Arrays and the Commutative Property

- [ ] `array_rows_columns`
  - Identify rows and columns in arrays.
- [ ] `commutative_property_matching`
  - Match equivalent multiplication facts.
  - Example: 3 × 4 = 4 × 3.
- [ ] `draw_arrays`
  - Draw or complete arrays for multiplication expressions.
- [ ] `valid_invalid_arrays`
  - Decide whether an arrangement is a true array.
- [ ] `mixed_evaluation`
  - Weekly review for arrays and commutative property.

### Week 3: Introduction to Division — Fair Sharing

- [ ] `fair_sharing_division`
  - Divide items equally among groups.
- [ ] `division_vocabulary`
  - Identify dividend, divisor, and quotient.
- [ ] `measurement_division`
  - Find how many equal-size groups can be made.
- [ ] `division_drawings`
  - Model division with circles/rings/drawings.
- [ ] `mixed_evaluation`
  - Weekly review for division foundations.

### Week 4: Inverse Operations and the Multiplication Link

- [ ] `fact_families`
  - Build related multiplication and division equations.
- [ ] `array_fact_families`
  - Use arrays to generate multiplication/division facts.
- [ ] `missing_numbers_inverse_operations`
  - Solve missing factors or quotients using inverse operations.
- [ ] `operation_choice_word_problems`
  - Choose multiplication or division for word problems.
- [ ] `mixed_evaluation`
  - Weekly review for inverse operations and fact families.

### Week 5: Core Problem-Solving Strategies

- [ ] `skip_counting_number_line`
  - Use number lines to model multiplication/division.
- [ ] `associative_property`
  - Understand grouping factors differently.
- [ ] `unknown_product_group_size`
  - Identify whether a problem asks for total product or group size.
- [ ] `comprehensive_reasoning_review`
  - Mixed multi-step reasoning practice.
- [ ] `unit_1_evaluation`
  - Full Unit 1 review.
